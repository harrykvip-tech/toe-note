# တို့မှတ်စု (Android app)

1. ဒီ folder တစ်ခုလုံးကို GitHub repo အသစ်ထဲ upload လုပ်ပါ (`main` branch)။
2. GitHub > **Actions** > "Build Android APK" ပြီးအောင် စောင့်ပါ (၅-၁၀ မိနစ်)။
3. ပြီးရင် run ထဲက **Artifacts > toe-note-apk** ကို download လုပ်၊ zip ဖြည်ပြီး `app-debug.apk` ကို ဖုန်းမှာ install လုပ်ပါ။

App ကို ပြင်ချင်ရင် `www/index.html` ကို ပြင်ပြီး push လုပ်ရုံပါပဲ။
